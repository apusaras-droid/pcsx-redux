## 解析方法

各資源の先頭から既知の命令境界だけをたどる。
0x50の絶対位置ジャンプ、0x52の条件式と二つの後続経路を追跡する。
条件の成立可能性は判定せず、両経路を候補として採用する。
0x5Fの資源移行ではその経路を終了する。
未知の命令を飛ばして途中のバイトを命令として再検索することはしない。
命令領域の重複を検出した資源は、その資源の参照結果をすべて保留する。

既知の命令長の根拠（意味が確定しているとは限らない）:

| 命令 | 長さ・後続 | 根拠となる実行コード |
| --- | --- | --- |
| 05 | 2 | 0x80018634 / 0x80018668 |
| 09 | 1 | 0x80018714 |
| 16 / 17 | 待機後に1 | 0x8001911C / 0x800195C0 |
| 28 | 4 | 0x80019D10 |
| 30 | 5 | 0x80019E30、ほか同処理内の完了経路 |
| 31 | 4 | 0x8001A128 |
| 39 | 2 | 0x8001A3F8 |
| 50 | 次の2バイトがLEの資源内絶対位置 | 0x8001A580 |
| 52 | 可変長条件列、成立時は直後、不成立時は指定位置 | 0x8001A5AC〜0x8001A834 |
| 60〜62 / 68 | 3 | 0x8001AC6C〜0x8001ADA4 |
| 80 / 81 | 3 / 2 | 0x8001AF58 / 0x8001AFDC |
| 85 | 4（+4の次命令も先読みする） | 0x8001B068 / 0x8001B094 |
| 87 / 90 / 91 | 完了時に1 | 0x8001B0C4 / 0x8001B17C / 0x8001B16C |

文章命令0x10はCP932の文字境界を確認し、今回扱う終端81 66 00以外は停止する。
文章内容そのものをCSVへ転載しない。
比較演算子は実行コードのセレクター番号を保持し、複合条件の意味を過剰に要約しない。
