# ONE シナリオのフローチャート

2026-09-20。対象はDisc 1 / SLPS-01972。
既存の命令解析結果とコードの照合から作成した部分図。
場面名は実行ファイルに残った名前。変数の意味は未確定。
アドレスではなく、各展開済みシナリオ内の相対位置を `+0x...` で示す。

## 初期化から冒頭へ

```mermaid
flowchart TD
    I["INIT：初期化用シナリオ"] --> V["+0x00〜0x0C：数値変数を設定<br/>変数10＝1<br/>変数6・12・13・14＝10"]
    V --> X["+0x0F：命令5F、引数63"]
    X -->|確認したロード経路| N["NV30：冒頭シナリオ"]
    X -.-> ALT["別条件での処理は未解明"]
    N --> Z["+0x00：変数0＝0"]
    Z --> U["+0x03：命令80 0D 01<br/>長さは確認、意味は未確定"]
    U --> T["+0x06：冒頭の文章を処理"]
    T --> W["+0x1C：命令16<br/>待機・入力処理の詳細は未確定"]
    W -->|完了した場合| T2["+0x1D：次の文章を処理"]
    T2 --> MORE["以降の解読済み範囲を進行"]
    MORE --> STOP["+0x3DD：命令11で解析停止"]
    classDef unknown fill:#fff3cd,stroke:#947000,color:#302600;
    class ALT,U,W,STOP unknown;
```

INITの5つの代入値は冒頭RAMと一致。NV30の展開結果36,619バイトもRAMと一致した。
命令16は条件が満たされるまで同じ位置に留まる処理を含む。
図の矢印は即時に次へ進むことを意味しない。

## フラグ80の受け渡し

この図の点線は、同じ状態を読み書きする関係。場面間の直接移行ではない。
保存先もカードファイル内オフセットではなく、内部の128バイトレコード内の位置。

```mermaid
flowchart LR
    M["MZ21 +0x12<br/>命令68：フラグ80をON"]
    F[("実行中のフラグ80<br/>RAM 0x800FA812、mask 0x01")]
    S[("内部保存レコード<br/>+0x32、mask 0x01")]
    D["DS25 +0xE8<br/>フラグ80が1か判定"]
    A["NA25 +0xD5<br/>フラグ80が1か判定"]
    M -.->|書き込み| F
    F -.->|参照| D
    F -.->|参照| A
    F -.->|状態レコードへのコピー| S
    S -.->|対応する復元処理| F
```

フラグ80の物語上の意味、ほかの書込み箇所、これらの場面へ到達する条件は未確定。
非ゼロのフラグを実カードへ保存してロードする往復検証も未実施。

## DS25のフラグ80による分岐

```mermaid
flowchart TD
    D["DS25の先行処理"] --> C{"+0xE8：フラグ80＝1？"}
    C -->|はい| YES["+0xF1：文章命令10"]
    YES --> YSTOP["文章内の追加制御が未解明<br/>この経路の解析はここで停止"]
    C -->|いいえ| NO["+0x4B9へ移動<br/>別の文章命令10"]
    NO --> NREST["以降の解析済み命令へ"]
    NREST --> NSTOP["後続にも未解明の命令あり"]
    classDef unknown fill:#fff3cd,stroke:#947000,color:#302600;
    class YSTOP,NSTOP unknown;
```

根拠となる命令列は `52 01 50 40 01 01 00 B9 04`。
単一条件を比較し、成立時は次の命令、不成立時はLEの指定位置0x04B9へ進む。
